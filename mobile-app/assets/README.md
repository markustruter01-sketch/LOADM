# Mobile App Assets

This directory contains all visual assets for the LOADMworkflow mobile application.

## Required Assets for App Store Submission

### App Icons (Required)
- `icon.png` - 1024x1024px - App Store icon
- `adaptive-icon.png` - 1024x1024px - Android adaptive icon (if needed)

### Splash Screen
- `splash.png` - 2732x2048px - iPad Pro splash screen (landscape)

### Additional Icons
- `favicon.png` - 32x32px - Web favicon

## Asset Creation Guidelines

### App Icon Design
- Clean, professional design representing military aviation
- Strong contrast for visibility on various backgrounds
- Avoid text or fine details that won't be visible at small sizes
- Use the LOADMworkflow branding colors

### Splash Screen Design
- Landscape orientation optimized for iPad
- Quick loading experience
- Consistent with app branding
- Minimal design to reduce perceived loading time
